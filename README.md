# Noun Quest — Detective Academy

A colourful, level-based English learning game for practising **common nouns, proper nouns and abstract nouns**.

## What the game includes

- Progressive levels that introduce harder noun challenges
- Common / proper / abstract noun classification
- Nouns inside sentences
- Proper-noun capital letter challenges
- Matching common nouns with specific proper nouns
- Mixed noun-pair challenges
- Correct-answer highlighting and a clear explanation after every wrong answer
- Score, streak bonuses, hearts and accuracy
- Detective ranks that unlock as the player progresses
- Built-in sound effects using the Web Audio API — no audio files or downloads required
- Animated feedback, confetti and responsive child-friendly visuals
- Local progress saving with `localStorage`
- Mobile, tablet and desktop support
- No framework or external dependency required

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server.

## Deploy

This repository is a static site and can be deployed directly with GitHub Pages, Vercel, Cloudflare Pages or another static host. No build command is required.

## Files

- `index.html` — game screens and accessible UI structure
- `styles.css` — responsive visuals, animations and game states
- `game.js` — question bank, progression, scoring, sound and game logic

## Learning design

The game starts with straightforward noun classification and gradually adds context, capitalization and mixed noun reasoning. When a player chooses a wrong answer, the game displays and highlights the correct answer and explains why it is correct before continuing.
